# Задачи по проекту для первого прототипа

> Legacy/context: этот список описывает состояние первого single-player FPS-прототипа на 19.03.2026.
> Актуальное направление разработки теперь зафиксировано в [Docs/NOTION_GDD.md](Docs/NOTION_GDD.md), а текущий мелкий backlog - в [Docs/PHASE_1_BACKLOG.md](Docs/PHASE_1_BACKLOG.md).
> Не использовать этот файл как основной список новых задач; он нужен для понимания уже собранного фундамента.

Актуально на 19.03.2026.

Источник: история коммитов, текущая структура проекта и незакоммиченные изменения в рабочем дереве.

## Сделано

- Подготовлена базовая структура UE-проекта и рабочая сборка проекта.
- Настроен базовый игровой цикл для персонажа: управление, прыжок, спринт, взаимодействие и HUD.
- Реализован базовый combat foundation: стрельба, перезарядка, переключение оружия, прицеливание и обработка попаданий.
- Добавлены компоненты здоровья, зон попадания и тестовые объекты для проверки урона.
- Добавлена система валюты игрока.
- Подключено первое оружие и подготовлена его логика, анимации и базовая интеграция в персонажа.
- Подключено второе оружие, включая отдельные ассеты, анимации и отображение в loadout.
- Собран UI HUD и кроссхейр для боевой части прототипа.
- Реализована система магазина оружия.
- Реализован терминал взаимодействия с магазином оружия.
- Реализована система armory/inventory:
  - хранилище предметов,
  - loadout-слоты,
  - карточки предметов,
  - тултипы,
  - перемещение предметов между инвентарём и loadout.
- Связаны между собой магазин, валюта, инвентарь и экипировка оружия.
- Подготовлены и подключены основные first-person / weapon animation assets.
- Настроен тестовый уровень и контент для проверки боевого и UI-цикла.

## В работе

- Система сохранения/загрузки прогресса:
  - добавлен `ProjectSaveSubsystem`,
  - заведены `SaveGame`-классы и индекс слотов,
  - добавлены структуры для сохранения состояния игрока, мира и боезапаса,
  - добавлен `SaveableActorComponent` для акторов мира,
  - начата интеграция quick save / quick load в `MainPlayerController`,
  - начата интеграция сохранения HP, валюты, инвентаря, loadout и патронов.
- Подключение input actions для сохранения/загрузки в input mapping.
- Завершение shutdown/quit flow через `ProjectGameViewportClient`, чтобы корректно отрабатывать закрытие окна в standalone.

## Осталось сделать

- Довести save/load до полностью рабочего сценария без ручных доработок в редакторе.
- Проставить и проверить `SaveableActorComponent` на всех нужных акторах прототипа.
- Проверить восстановление состояния мира после загрузки:
  - уничтоженные объекты,
  - повреждённые объекты,
  - кастомные состояния акторов.
- Проверить полное восстановление состояния игрока после загрузки:
  - позиция,
  - поворот камеры,
  - здоровье,
  - валюта,
  - loadout,
  - содержимое инвентаря,
  - активное оружие,
  - патроны в магазине и резерве.
- Финально привязать save/load к блюпринтам, input assets и уровню, чтобы сценарий работал без кодовых доправок.
- Прогнать end-to-end сценарий первого прототипа:
  - зайти на уровень,
  - пострелять,
  - получить/потратить валюту,
  - купить оружие,
  - переложить его в loadout,
  - сохранить игру,
  - загрузить игру,
  - убедиться, что всё восстановилось корректно.
- Добить минимальную полировку UX для прототипа:
  - понятные сообщения о сохранении/загрузке,
  - проверка блокировок ввода при открытых overlay,
  - проверка конфликтов между inventory/shop/save input.
- Прогнать smoke-test сборки и игрового сценария после завершения save/load.
